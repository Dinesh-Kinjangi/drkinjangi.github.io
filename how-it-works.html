How FlowAgents works

Dinesh Kinjangi · agentic thermal design engineer · PhD thermal CFD · thermal design engineer at ATS (Boston)

FlowAgents is a portfolio site for two prototypes I build on nights and weekends. The interactive demos need JavaScript. This page is for recruiters, link previews, and anyone who wants the story in thirty seconds without loading the app.

Spread (calculate)

Agentic thermal sizing: heatsinks, cold plates, heat exchangers, CDU selection.

  • You describe geometry and conditions in plain language.
  • An agent extracts parameters and runs numpy physics (Teertstra bypass, spreading resistance, and related models).
  • The site demo runs heatsink physics in the browser on flowagents.dev. No server required for the public demo.
  • Source stack: Python FastAPI backend in a separate repo when you run it locally.

Residual (simulate)

Thermal CFD workflow for electronics cooling: OpenFOAM case structure, mesh QC, residual plots.

  • The live site shows parsed log output and mesh summary from a real channel case (static JSON).
  • Full Jupyter-native IDE runs locally on port 3001.
  • Not general-purpose cloud CFD. Thermal cases only.

Remember (literature)

On-prem RAG over datasheets and test reports with chunk citations. Sample answer on the AI as Tool page. Built first at ATS for internal use.
